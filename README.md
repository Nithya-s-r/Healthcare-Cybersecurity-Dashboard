# 🏥 Healthcare Cybersecurity Dashboard

## 📊 Project Overview
This project analyzes cybersecurity vulnerabilities in healthcare systems using real CVE data from NVD.

## 🔍 Key Insights
- Distribution of vulnerabilities by severity
- Most common attack vectors
- Frequently occurring weaknesses (CWE)
- Trends over time
